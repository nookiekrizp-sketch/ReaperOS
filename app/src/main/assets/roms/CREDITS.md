# Bundled homebrew games

These freely distributed homebrew games are included with ReaperOS unmodified, with thanks to their authors. Each one's source code, license and newest version live at its project page.

| Game | System | Author | Project |
|---|---|---|---|
| Nova the Squirrel | NES | NovaSquirrel | https://github.com/NovaSquirrel/NovaTheSquirrel |
| Thwaite | NES | Damian Yerrick (pinobatch) | https://github.com/pinobatch/thwaite-nes |
| Concentration Room | NES | Damian Yerrick (pinobatch) | https://github.com/pinobatch/croom-nes |
| Libbet and the Magic Floor | Game Boy | Damian Yerrick (pinobatch) | https://github.com/pinobatch/libbet |
| µCity | Game Boy Color | Antonio Niño Díaz (AntonioND) | https://github.com/AntonioND/ucity |

The games run in ReaperOS's built-in player, which uses EmulatorJS (https://github.com/EmulatorJS/EmulatorJS, GPL-3.0) loaded from its official CDN.
